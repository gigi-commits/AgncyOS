# AgncyOS Widget

> Embeddable AgncyOS widget for artist identity, royalty ingestion, real-time valuation, instant offers via **AgncyCapital**, and payouts via **AgncyPay**.

## ✨ What it does
- **Authenticate artists** (OAuth/token)
- **Ingest royalties** (linked DSP/PRO/publisher accounts; read-only)
- **Generate live valuation** with AgncyOS
- **Present and accept offers** via AgncyCapital
- **Trigger instant payouts** via AgncyPay

## 🧱 Architecture
- **Phase 1:** iFrame widget (fastest path; drop-in)
- **Phase 2:** JS/React SDK (styling, events, deeper partner integration)
- **Backend:** Secure service powering auth, data fetch, valuation, offers, payouts.
